# 书库 · Book Library for DeepSeek Harness

在 DSH 左侧栏放一个自己的书库：把书导进来，让它一章一章讲给你听懂，念出来听，随时打断提问。

不是摘要工具，也不是目录搬运工。核心是**逐章真正读懂**——这一章在整本书里干什么活、作者为什么这么写、写到人的哪一处、讲的人自己怎么看。有观点，可以不同意作者。

## 它能做什么

- **导入书本和文章**：EPUB / TXT / Markdown 选文件直接上传，自动切章、自动认书名（文件名是 `55449.txt` 也能从正文里认出真名），认错了点书名就能改。
- **逐章讲解**：点任意一章，讲解框里当场流式生成，落到本地后就是缓存，不再花钱。固定五段式：

  | 段落 | 写什么 |
  | --- | --- |
  | 本段落概括 | 两三句说清谁、在哪、发生了什么、停在哪。只交代事实，不评论不抒情。 |
  | 文章美句 | 挑两三句原书句子逐字抄（一个字都不改），标段号，说清好在哪。没有就直说没有，不许自己造。 |
  | 作者表达 | 作者想说什么、怎么说的；这一章在全书里是起势、铺陈、转弯还是收口。 |
  | AI 观点 | 自己的判断：哪里好、哪里偷懒、哪里绕远了，允许不同意作者。 |
  | AI 认为需要补充点 | 作者漏掉或绕开的地方、哪个前提没交代、读者该补什么。 |

  篇幅跟着原文走：正文几十字就只给一两句话，正文长才写长——**讲解不会比原文还长**。
- **念出来听**：接豆包（火山引擎）语音合成，也可以选 Mac 自带朗读。语气跟着情节走——沉重处低沉、轻松处轻快，由模型读内容自己定，不用手选。
- **原文对照**：讲解正文里的段号 `[7]` 可点，点一下滚到下面原文第 7 段并高亮；讲到哪段，原文对应段落自动淡色标出。原文只显示讲到的那几段。
- **边听边问**：播放条下常驻提问框，随时问「这一段为什么这么写」。
- **即时答疑**：不绑章节，就着整本书问。
- **接着听**：一章念完自动接下一章；没讲过的章会先讲一遍再念。同一时间只响一路声音。
- **导出**：把讲过的章节装订成一份单页 HTML，能打印、能转发。
- **书架管理**：书封右上角「⋯」里改书名、删除、看内容简介；字号可以拖，界面整体缩放不影响 DSH 其它地方。

## 安装

```
dsh plugin install dsh-book-library
```

或在 DSH 的插件市场里搜「书库」一键安装。装完左侧栏出现「书库」图标。

## 用之前的两件事

1. **文字讲解**走 DSH 当前的默认模型，不用额外配置——去 DSH 设置里挑一个模型即可。
2. **念出来听**需要一个语音服务。默认接豆包（火山引擎）：在「设置」里填应用号（App ID）和访问密钥；也提供本机朗读（macOS 自带 `say`）作为零成本备选。

## 数据在哪

全部在本机：`$DSH_HOME/deep-reading/books/`（默认 `~/.dsh/deep-reading/books/`）。

每本书一个目录，章节、讲解、章节记忆都是纯 Markdown——**书和笔记不会被锁在某个数据库里**，随时能用别的编辑器打开、备份、搬走。删除书籍不真删，移到 `~/.dsh/book-library/trash/`，误删可以捞回来。阅读偏好存在 `~/.dsh/book-library/preference.md`。

## 隐私

- 书和笔记只存在本机，不上传任何服务器。
- 发给模型的内容只有完成当前任务所需的部分：当前这一章正文、书名与章节目录、你的阅读偏好。
- 语音合成只把要念的那段文字发给所选语音服务。
- 导出在浏览器里直接生成文件，不经过第三方。

## 与 deep-reading 的关系

读写格式与 `dsh-deep-reading` 完全一致（`book.json` + `chapters/NNN.md` + `lecture/` + `memory/`），两边的成果可以互相看见。本插件自带导入器，**不依赖** deep-reading 的原生模块，所以在缺少原生二进制的机器上也能导入。
